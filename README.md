# Carmen Olmeda — Engineering Portfolio

Static responsive multi-page portfolio based on the supplied Canva PDF.

## Publish for free with GitHub Pages
1. Create a **public** repository named `<your-username>.github.io` on GitHub.
2. Upload **all files and the `assets` folder** from this project to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**. Save.
4. Visit `https://<your-username>.github.io/` after GitHub Pages deploys.

Alternatively use any repository name and the URL will normally be `https://<your-username>.github.io/<repo-name>/`.

## Edit
- Text and links: edit `.html` files.
- Colors and layout: `style.css`.
- Images: `assets/` (some images were cropped from the supplied PDF and may be lower resolution; replace with original Canva uploads for sharper results).
- Review your public phone number before publishing.

No Canva account, paid hosting, or build tools required.
